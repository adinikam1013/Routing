====================================================
SCENARIO 1 - WRONG NEIGHBOR IP
====================================================

R1

conf t

router bgp 65001
 no neighbor 10.1.1.2 remote-as 65002
 neighbor 10.1.1.100 remote-as 65002

end

Verify:

show ip bgp summary

Expected:

State = Active

Troubleshooting:

show run | section bgp

Fix:

router bgp 65001
 no neighbor 10.1.1.100 remote-as 65002
 neighbor 10.1.1.2 remote-as 65002

====================================================
SCENARIO 2 - WRONG REMOTE-AS
====================================================

R1

conf t

router bgp 65001
 no neighbor 10.1.1.2 remote-as 65002
 neighbor 10.1.1.2 remote-as 65003

end

Verify:

show ip bgp summary

Expected:

State = Active

Troubleshooting:

show run | section bgp

Fix:

router bgp 65001
 no neighbor 10.1.1.2 remote-as 65003
 neighbor 10.1.1.2 remote-as 65002

====================================================
SCENARIO 3 - INTERFACE DOWN
====================================================

R2

conf t

interface GigabitEthernet0/0
 shutdown

end

Verify R1:

show ip bgp summary

Expected:

State = Idle

Troubleshooting:

show ip interface brief

Fix:

interface GigabitEthernet0/0
 no shutdown

====================================================
SCENARIO 4 - IP ADDRESS MISMATCH
====================================================

R2

conf t

interface GigabitEthernet0/0
 ip address 10.1.2.2 255.255.255.252

end

Verify:

ping 10.1.1.2

Expected:

Fail

show ip bgp summary

Expected:

State = Active

Fix:

interface GigabitEthernet0/0
 ip address 10.1.1.2 255.255.255.252

====================================================
SCENARIO 5 - NO IP CONNECTIVITY
====================================================

Check:

ping 10.1.1.2

If Ping Fails:

BGP Will Not Establish

Check:

show ip interface brief

show ip route

====================================================
SCENARIO 6 - TCP PORT 179 BLOCKED
====================================================

Apply ACL Blocking TCP/179

Expected:

State = Active

Check:

show access-lists

Fix:

Remove ACL Or Permit TCP 179

====================================================
COMMON BGP STATES
====================================================

Idle
  BGP Not Started

Connect
  TCP Connection In Progress

Active
  Unable To Establish TCP Session

OpenSent
  OPEN Message Sent

OpenConfirm
  Waiting For KEEPALIVE

Established
  Neighbor Up And Exchanging Routes

====================================================
BGP STATE VS POSSIBLE ISSUE
====================================================

STATE          POSSIBLE ISSUE

Idle           BGP process not started
               Interface down
               Neighbor shutdown
               Configuration missing

Connect        TCP connection in progress
               Normally temporary state

Active         Wrong neighbor IP
               Wrong subnet
               No IP connectivity
               ACL blocking TCP 179
               Interface down
               Routing issue

OpenSent       ASN mismatch
               BGP version mismatch
               OPEN message problem

OpenConfirm    Waiting for KEEPALIVE
               Usually temporary state

Established    No issue
               BGP session successfully established

====================================================
MOST COMMON REAL-WORLD ISSUES
====================================================

Active         90% of the time:
               Ping failure
               Wrong Neighbor IP
               ACL blocking TCP 179

OpenSent       Usually:
               Wrong Remote-AS

Idle           Usually:
               Interface shutdown
               Neighbor configuration missing

Established    Healthy state
