====================================================
OBJECTIVE
====================================================

1. Configure eBGP Peering
2. Advertise Loopback Network Using Network Command
3. Verify Route Advertisement
4. Verify Route Installation In Routing Table

====================================================
R1 CONFIGURATION
====================================================

enable
configure terminal

hostname R1

interface GigabitEthernet0/0
 ip address 10.1.1.1 255.255.255.252
 no shutdown

interface Loopback0
 ip address 1.1.1.1 255.255.255.255

router bgp 65001
 neighbor 10.1.1.2 remote-as 65002
 network 1.1.1.1 mask 255.255.255.255

end

write memory

====================================================
R2 CONFIGURATION
====================================================

enable
configure terminal

hostname R2

interface GigabitEthernet0/0
 ip address 10.1.1.2 255.255.255.252
 no shutdown

interface Loopback0
 ip address 2.2.2.2 255.255.255.255

router bgp 65002
 neighbor 10.1.1.1 remote-as 65001
 network 2.2.2.2 mask 255.255.255.255

end

write memory

====================================================
IMPORTANT NOTE
====================================================

For BGP Network Command To Work:

1. Network Must Exist In Routing Table
2. Mask Must Match Exactly

Example:

Loopback0
 ip address 1.1.1.1 255.255.255.255

router bgp 65001
 network 1.1.1.1 mask 255.255.255.255

If Mask Does Not Match:

network 1.1.1.0 mask 255.255.255.0

Then Route Will NOT Be Advertised.

====================================================
TEST NETWORK COMMAND FAILURE
====================================================

R1

router bgp 65001
 no network 1.1.1.1 mask 255.255.255.255
 network 3.3.3.3 mask 255.255.255.255

Verify:

show ip bgp

Expected:

3.3.3.3/32 Will NOT Appear

Reason:

Route Does Not Exist In Routing Table

Restore:

router bgp 65001
 no network 3.3.3.3 mask 255.255.255.255
 network 1.1.1.1 mask 255.255.255.255
